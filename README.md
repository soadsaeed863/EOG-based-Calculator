#  EOG-based Calculator

A hands-free calculator controlled by eye movements and blinks. The system classifies Electrooculography (EOG) signals with machine learning and maps them to calculator actions through a Python GUI. Built as a Human-Computer Interaction (HCI) project.

##  Features
- Eye movement and blink detection from EOG signals
- ML classification of signal patterns
- Python GUI calculator controlled without physical touch
